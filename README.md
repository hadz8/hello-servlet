# hello-servlet (Tomcat)

## What it does
A Java servlet that prints: `Hello + first and last name`.
An `index.html` page links to the servlet.

## Software Used
- JDK
- IntelliJ IDEA Ultimate
- Apache Tomcat

## Build
Build from IntelliJ Maven tool window:
- Lifecycle -> package
Output: `target/hello-servlet.war`

## Deploy and Test
- Open: http://localhost:8080/hello-servlet/
- Servlet: http://localhost:8080/hello-servlet/hello
